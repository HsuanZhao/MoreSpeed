# 网课变速助手 - 上海律协网课专用

这是一个浏览器扩展，专门用于**变速播放上海律协网课视频**，支持倍速播放、音高保持、快捷键控制等高级功能。

## ✨ 主要功能

- **倍速播放**：0.07x ~ 16x 任意调节，默认保持音高不变
- **快捷键控制**：无需鼠标，一键增速/降速/重置
- **音高保持**：变速时不改变声音的“尖细感”，保持自然
- **音效调节**：可调整音量、音调、延迟等
- **全局生效**：在任意标签页中都可控制当前激活的视频

## 🚀 快速开始

### 安装方法（推荐使用360浏览器）

1. 下载本扩展的所有文件到一个文件夹中（保留完整目录结构）
2. 打开 **360浏览器**（极速模式），在地址栏输入：`chrome://extensions/` 并回车
3. 打开右上角的 **“开发者模式”** 开关
4. 点击 **“加载已解压的扩展程序”**，选择刚才的文件夹
5. 扩展安装成功后，浏览器工具栏会出现图标

> ⚠️ **建议使用360浏览器**：部分网课平台对内核有特殊兼容性，360浏览器兼容性较好。使用完毕后，建议**卸载该扩展**，以免影响其他正常视频观看。

### 基本使用

- 打开任意视频页面（如上海律协网课）
- 使用以下快捷键控制播放速度：

| 快捷键 | 功能 |
|--------|------|
| **A** | 降速 0.1x |
| **S** | 重置速度为 1x |
| **D** | 增速 0.1x |
| **Q** | 固定当前标签页速度（不受全局影响） |
| **Shift + Q** | 全局开关（启用/禁用扩展） |
| **Z** | 后退 5 秒 |
| **X** | 前进 10 秒 |
| **Shift + Z** | 后退 0.041 秒（精准微调） |
| **Shift + X** | 前进 0.041 秒（精准微调） |
| **Shift + F** | 全屏切换 |
| **Shift + W** | 打标记（mark1） |
| **W** | 跳转到标记（mark1） |
| **R** | 循环播放标记区间（需手动启用） |

> 部分快捷键默认可能被浏览器占用，可按需修改扩展中的配置。

## ⚙️ 高级设置

点击扩展图标，可以：
- 调整默认倍速
- 修改快捷键绑定
- 启用/禁用滤镜（反色、模糊等）
- 设置音效（均衡器、音调偏移、延迟）

## 🧹 卸载说明

1. 进入 `chrome://extensions/`
2. 找到“网课变速助手”，点击 **“移除”**
3. 如需彻底清理，可同时清除浏览器缓存

## ❓ 常见问题

**Q：为什么变速后声音变得很奇怪？**  
A：请检查“音高保持”功能是否开启（扩展默认开启）。如果关闭，变速会改变音高。

**Q：快捷键没反应？**  
A：确保当前页面焦点在视频区域（或任意空白处），且扩展未被禁用。部分网站会拦截快捷键，可点击扩展图标临时关闭后重新启用。

**Q：视频播放没有变速效果？**  
A：尝试刷新页面，或检查扩展图标是否显示为彩色（灰色表示已禁用）。若仍无效，可能是该网站使用了特殊的播放器，请反馈。

**Q：为什么建议用360浏览器？**  
A：部分网课平台对 Chromium 内核有兼容性问题，360浏览器的兼容模式能更好支持扩展注入。用完后请及时卸载，避免影响日常浏览。
